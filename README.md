One word that describes home Wi-Fi as everyone actually lives it: Ghosting, for the make.fun competition "One Word for Your Wi-Fi".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> Ghosting

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
